# XtraTrax

Add your own music to **Need for Speed Underground 2**, alongside the original songs.

## Before you start

**Requires 64-bit Windows. No Python installation is needed.**

Download **XtraTrax-0.3.10.zip** to run the app. The separate source ZIP is for developers.

Use the ready-to-run XtraTrax download from NFSMODS. GitHub's **Code > Download ZIP** contains source code, not the app.

**You need an ASI loader installed in the game. XtraTrax does not include one.**

If you do not already have one, get [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/latest). Download **Ultimate-ASI-Loader.zip** (not the x64 version) and extract `dinput8.dll` into the game folder, beside `SPEED2.EXE`. If that file already exists, do not overwrite it.

Supported game versions: **US 1.2, LGU, and MagiPack v5**. XtraTrax checks your copy before installing; not every modified copy is supported.

## Add your music

1. Close the game.
2. Extract the whole XtraTrax ZIP into its own folder. Open **XtraTrax.exe**.
3. Click **Select UG2 Installation Path**. Choose the folder containing **SPEED2.EXE**.
4. Click **Add Songs** and choose your music.
5. Click **Apply Patch**. Wait for the success message, then start the game.

Use **MP3, WAV, FLAC, M4A, or Ogg** files. You can add up to **100 songs**.

Leave the optional checkboxes off to start. Volume matching takes longer and may change how your songs sound.

**Changing your playlist later? Add every song you want to keep before applying again. Each patch replaces your previous custom playlist.**

## Undo it

Close the game, open XtraTrax, select your game folder, and click **Restore to Default**.

Keep the **XtraTraxBackup** folder in your game folder. XtraTrax needs it to restore your music.

## Something went wrong?

Report problems in the **NFSMODS mod comments or by DM on NFSMODS**. Include your XtraTrax version and a screenshot of the error. Keep your backup folder.
